# AI私教 · 一个能自己进化的家庭练习系统

给自家孩子做的每日练习系统。它不只出题——**它记录、诊断、然后告诉你该补哪里**。

做这个的起因很朴素：孩子每天做题，家长只知道"错了 6 道"，不知道**为什么错**、**该补什么**、**明天该做什么**。

---

## 它解决什么问题

| 常见做法 | 问题 | 这个项目 |
|---|---|---|
| 买练习册 | 不知道孩子卡在哪，只能一本本刷 | 每次作答都落到知识点上，能看到"哪个点不行" |
| 用 APP 刷题 | 错了就推同类题，治标不治本 | 沿知识图谱往上追，找出**前置知识点**的断层 |
| 家长人工分析 | 费时，且看不出跨册的因果链 | 一条命令跑完全流程 |

核心是那句话：**做错一道题，可能不是因为这道题的知识点没掌握，而是三年前某个前置概念塌了。**

---

## 三个特点

### 1. 知识图谱驱动

内置小学数学 **284 个知识点、459 条先修依赖**（另有语文 494、英语 275 个点，共 1053 个）。

每个知识点带：
- 人教版章节定位（几年级哪一单元）
- **掌握标准**（2–3 条"能做到什么"）
- 前置依赖（要学它，先得会什么）

诊断时沿着"前置"往上追三层，能告诉你：**"这道题错，可能是三年级的笔算乘法没过关"**。

### 2. 三套题库协同

| 库 | 装什么 | 怎么来 |
|---|---|---|
| 错题库 | 孩子做错的原题 | 拍照采集 / 拍照录入 |
| 变式题库 | 错题的变式 | 由错题派生，检验有没有真掌握 |
| 大纲题库 + 题库 | 按教材进度该会的题 | 按课标自己出 / 开源题库 |

做错的开源题和大纲题会自动进复习排期，按 **D+1 / D+7 / D+21** 间隔重做。

### 3. 公式可调，不写死

题量、难度、节奏判断的参数都在 `题库/tuning.json`，改完跑一次构建就生效。

配套的 `调参指引.md` 写了：看到什么现象、该动哪个参数、三条纪律（一次只动一个、难度优先于题量、正确率跌破 60% 就停手）。

## 快速开始

### 第一步：起本地服务

```bash
python 题库/build.py          # 建索引
python 知识库/score.py        # 知识点评分
python 题库/lifecycle.py      # 复测排期
python 题库/checkin.py        # 打卡与星星
python 网站/build_site.py     # 生成整站 → 刷题/app/
```

然后 `cd 刷题/app && python -m http.server 8000`，浏览器打开 `http://localhost:8000`。

### 第二步：接自己的云端（可选）

项目用 [WorkBuddy 云服务](https://www.workbuddy.cn) 存作答记录，这样手机和电脑能同步。

不接也能用——所有页面都有本地兜底。

接的话：
1. 在 `网站/build_site.py` 里填你自己的 `CLOUD_ENDPOINT` 和 `CLOUD_KEY`
2. 建两张表：`drill_submissions`（作答）、`star_withdrawals`（星星提取）

### 第三步：放你自己的题

打开 `大纲题库/题库.json`，按现有格式加题。加完跑：

```bash
python 大纲题库/check.py     # 校验结构
python 大纲题库/rate.py      # 按五维标准算难度
```

```
  build_site.py      整站生成器（唯一入口）
  assets/            引擎、样式、题库包

刷题/
  make_drill.py      做题页模板
  app/               发布目录（构建产物）

调参指引.md          ★ 看到什么现象改哪个参数
```

## 几个设计上的取舍

**为什么不用现成的刷题 APP**
现成 APP 的推荐逻辑是"错了推同类"，但孩子真正的问题往往在更早的地方。知识图谱能把这个问题显性化。

**为什么题量不是越多越好**
系统判"快而错"时不会加题，而是**提难度**。做题快不等于会，可能只是题太简单。加题只会让她更赶。

**为什么难度设下限**
早期版本有个死循环：错得多 → 分数低 → 给更简单的题 → 秒答 → 还是错。现在难度最低 4 分档，不给"秒答级"的题。

---

## 已知限制

1. **开源题库的答案没有人工审核过**，可能有错。孩子做错时建议看一眼解析。
2. **语文英语的图谱粒度**比数学粗（能力点 vs 知识点），跨单元的能力可能挂靠不准。
3. **首次加载约 1.9 MB**（含三科题库），4G 下 1–2 秒。可以按科目拆分优化。
4. **打印试卷依赖本机 Chrome**，云上跑不了。
