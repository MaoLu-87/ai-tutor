# 每日刷题

> 每周自动生成 7 天 × 2 组的练习页，输出到 `刷题/app/`。

## 主要脚本

| 脚本 | 作用 |
| --- | --- |
| `make_week.py` | 生成未来 7 天（每天两组），按知识点评分分配 |
| `make_drill.py` | 单场生成器（`--ids` / `--n` / `--out` / `--minutes`） |
| `make_daily.py` | 旧的单日生成器，保留作临时调试 |


> 已接入云数据库：做完自动上传一条记录，agent 可直接查询同步。
> 结果码保留作兜底——上传失败时仍可手发。

---

## 一、怎么生成一场

```bash
cd ./刷题
python make_drill.py                          # 出全部 6 题
python make_drill.py --ids M5A-005,M5A-009    # 只出指定几题
python make_drill.py --title "11月9日 · 数学回炉"
```

产物永远是 `drill.html`，单文件 10 KB 左右，可直接发布或拷贝。

## 二、iPad 怎么打开（局域网方案）

**双击 `启动刷题.bat`**，会弹出一个黑窗口，打印出地址，形如：

```
http://192.168.110.111:8000/
```

iPad 连上和电脑**同一个 WiFi**，Safari 输入这个地址即可。

- 打开后点「分享 → 添加到主屏幕」，以后点图标直接进，全屏无地址栏
- **窗口关掉服务就停**；电脑关机也不能用
- 第一次启动 Windows 可能弹防火墙提示，选「允许访问」（专用网络）
- 家里路由器重启后 IP 可能变，以黑窗口里打印的地址为准

> 这台机子当前是 `192.168.110.111`，端口 8000。

## 三、孩子看到的流程

1. 首页 → 点「开始」
2. 一题一屏，选择题点选项，填空题弹数字键盘
3. **答错先给一句提示，让他再试一次**；还错才显示正确答案
4. 做完显示得分、用时、错题编号
5. 点「复制结果码」→ 微信粘贴给家长

## 四、数据存哪

云端表 `drill_submissions`（WorkBuddy 云服务，PostgreSQL）：

| 字段 | 说明 |
| --- | --- |
| `id` | 自增主键 |
| `drill_date` | 场次日期 `YYYY-MM-DD` |
| `drill_title` | 场次标题 |
| `answers` | 结果码原文 |
| `score` / `total` | 得分 / 总题数 |
| `duration_sec` | 总用时（秒） |
| `created_at` | 提交时间 |

权限：匿名只能 `INSERT`，**不能读**。也就是说页面能写、但任何人都查不到别人的记录；读取走 agent 侧的 SQL。

查询示例：

```sql
SELECT drill_date, score, total, answers, created_at
FROM drill_submissions ORDER BY created_at DESC LIMIT 10
```

## 五、结果码格式（兜底用）

```
D20261109|M5A-005=1@12,M5A-006=0@35,M5A-007=1@8|55
```

- `D` + 年月日
- 每题：`题号=是否一次答对@用时秒`
- 最后一段：总用时秒

我拿到这串就能直接回写错题本的「复测记录」，不用你再说明。

## 六、题库怎么加题

编辑 `drill-bank.json`，按现有格式追加一条：

```json
{
  "id": "M5A-0XX",          // 必须与错题库里的编号一致
  "单元": "U5",
  "知识点": "用字母表示数",
  "类型": "choice",          // choice 或 number
  "题干": "……",
  "选项": ["…", "…", "…", "…"],   // 仅 choice
  "答案": 1,                 // choice 填索引(0=A)，number 填数值
  "提示": "答错时显示的一句提示",
  "显示": "3.00"             // 可选，覆盖答案的显示格式
}
```

**只收客观题**：选择、填空（数值）。竖式、脱式、解决问题、作文、阅读主观题一律留在纸上——

> 他现在的短板（小数点、进位、算式过程、作文收口）全在笔尖上，搬上屏幕会退化。

## 七、每天/每次怎么用

- 不定时，按复习排期推：我算出哪天有题到期，就生成一场发给链接
- 单场控制在 6–10 题、5 分钟内
- 做完当天把结果码发我，我更新复测记录和队列
