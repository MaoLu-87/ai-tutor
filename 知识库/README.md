# 知识点库

> 小学阶段三科知识点，按 **2022 版课标** 的「领域 → 主题」组织，不按教材册次（教材会换版本，课标不会）。

## 文件

| 文件 | 是什么 |
| --- | --- |
| `kps.json` | 知识点定义（129 个），含 id / 学段 / 领域 / 别名 |
| `scores.json` | 生成物：每个知识点的评分、证据数、上次时间 |
| `score.py` | 评分引擎 |

## 评分规则

| 情形 | 算法 | 说明 |
| --- | --- | --- |
| 初始 | `null`（未测） | 没做过就不给分，不参与薄弱排序 |
| 第一次作答 | 从 50 起算 | 单次证据不该给出太高或太低的分 |
| 答对 | `score += (100 − score) × 0.30` | 越接近满分，涨得越慢 |
| 答错 | `score × 0.75` | 一次错扣四分之一 |
| 时间衰减 | 每满 30 天 `× 0.92` | **知识会生疏**，一年不碰约剩 37% |

**分档**：≥85 熟练 ／ 70–84 掌握 ／ 50–69 待巩固 ／ <50 薄弱 ／ 无证据 未测。

评分可加可减：做对往上走，做错往下走，久不做自然下滑。三者叠加才是真实掌握度。

## 别名（alias）

题库里的知识点是自由文本（「用字母表示数」「说明文·语言准确性」），通过 `alias` 映射到标准知识点。

```json
{"id":"M-A-28","name":"用字母表示数与数量关系",
 "alias":["用字母表示数","数量关系","两位数位值","周长"]}
```

**匹配规则：最长别名优先。** 否则「小数乘法」会抢走「小数乘法·解决问题」。

`score.py` 会列出「未映射到知识点的题库标签」，看到就跑回来补 alias。

## 加知识点

在 `kps.json` 的 `知识点` 数组里追加，字段：

```json
{"id":"M-A-34","sub":"数","stage":"三","domain":"数与代数",
 "name":"标准名","alias":["题库里出现过的写法"]}
```

- `sub`：数 / 语 / 英
- `stage`：一（1–2 年级）/ 二（3–4）/ 三（5–6）
- `domain`：课标领域（数与代数、图形与几何、统计与概率、综合与实践；语文四领域；英语按语音/词汇/语法/功能/读写/听力）
- **id 不能重名，name 也不能重名**（脚本会报别名冲突）

## 每次数据变化后

```bash
python 知识库/score.py      # 重算评分
python 网站/build_site.py   # 重建知识地图页
```
